# Source profiles

These are discovery lanes, not automatic evidence rankings.

| Source lane | Default use | Default TTL | Constraint |
|---|---|---:|---|
| [UIUXShowcase](https://uiuxshowcase.com/) | Find candidate sources | 60 | Directory pages never count |
| [Recent](https://recent.design/websites) | Current visual direction | 60 | Inspect the showcased site; inspiration only |
| [Lookup.design](https://lookup.design/) | Component examples | 60 | Count a concrete underlying example |
| [Land-book](https://land-book.com/) | Page and section composition | 60 | Manual use only when current terms permit; no automated collection |
| [60fps.design](https://60fps.design/) and [Design Spells](https://designspells.com/) | Motion craft | 60 | Record trigger, timing, and transfer question |
| [Awwwards](https://www.awwwards.com/), [Dribbble](https://dribbble.com/), [Behance](https://www.behance.net/) | Possibility space | 60 | No usability claim without stronger evidence |
| Direct products and official product help | Real task flows | 90 | Record only observed states, ordinary constraints, and friction |
| [Baymard](https://baymard.com/), [GoodUI](https://goodui.org/), [Built for Mars](https://builtformars.com/) | Countercheck | 365 | Preserve applicability, method, and evidence limits |
| Public design systems | System and component craft | 180 | Inspect implementation, state coverage, and maintenance status |
| Optional paid libraries | Retrieval only when connected | 30 | Verify current access, billing, cancellation, and terms before use |

Default storage is `text-link-only`. Change it only when the exact source terms
or ownership explicitly permit local caching and record that basis in
`rightsNote`. Never scrape, mirror, or infer quality from corpus size,
popularity, or awards.
