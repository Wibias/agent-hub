# Pattern vocabulary

Name patterns so the agent can choose deliberately instead of reinventing.
Pair with `macrostructures.md`. Prefer named pick over freeform.

## Hero paradigms

| Name | Shape | Risk |
|---|---|---|
| Marquee | Fold is one statement/visual | Strong if committed |
| Stat-led | Giant real metric | Fake metrics = fail |
| Split diptych | Text | proof alternating | Default "premium" skeleton = slop if repeated |
| Quote-led | Pull quote + attribution | Needs real quotes |
| Photographic fold | Image dominates; text annotates | Needs real imagery |
| Letter | Intimate first-person | No button spam |
| Workbench | Real product UI primary | Best for tools |
| Clipped demo | Product bleeds viewport edge | Needs real capture |

**Default hero stack (slop):** eyebrow + H1 + sub + dual CTAs, often + right panel.
Break it deliberately.

## Nav

N1 minimal · N1b SaaS three-section · N2 floating chip · N3 side rail · N4 hidden cmdk ·
N5 floating pill · N6 masthead · N7 brutal slab · N8 terminal · N9 edge-aligned ·
N10 scroll-morph · N11 mega · N12 banner-retract · N13 inline cmdk pill.

Default **away** from wordmark + 5 links + right CTA + hairline.

## Footer

Ft1 mast · Ft2 inline · Ft3 index columns (hubs only) · Ft4 colophon · Ft5 statement ·
Ft6 letter close · Ft7 newsletter-first · Ft8 marquee.

Default **away** from 4-col Product/Company/Resources/Legal + social + copyright.

## Features / proof

Bento irregular · zig-zag 2-col · sticky feature stack · tabular spec · annotated screenshot ·
step sequence (only if real order) · catalogue grid.

**Banned default:** three equal icon-tile cards.

## Scroll / media

Sticky card stack · horizontal pan · reveal stagger · pin gallery · marquee (max one) ·
scroll-scrub type. See `motion-systems.md` skeletons.

## Micro

Press scale · hold-to-confirm fill · trigger-origin popover · toast same-edge enter/exit ·
shared layoutId morph · count-up (rare, real numbers).

## CWV checklist (ship bar)

- LCP < 2.5s (hero image priority / preload)
- INP < 200ms
- CLS < 0.1 (reserved image/font/embed space)
- No content gated on entrance animation (visible by default)
