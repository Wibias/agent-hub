# Genres - four visual families

Use genre as a direction aid, not a stereotype engine. Pick one dominant family
early when it helps scope macrostructure, motion level, and visual language. Blend
families only when the product/brand reason is explicit.

## Detection heuristic

| Signal in brief | Candidate genre |
|---|---|
| essay, magazine, portfolio, studio, type, foundry, editorial | **editorial** |
| SaaS, B2B, API, platform, dashboard, infra, developer tool | **modern-minimal** |
| generative, music/video, late-night, dark immersive, cinematic | **atmospheric** |
| consumer, family, community, casual, playful onboarding | **playful** |

These are candidates, not automatic assignments. Existing brand/system evidence
wins. When the brief is vague, test the candidate against product role and the
selected direction before committing.

## editorial

**Bias:** document intelligence, restraint, type-led hierarchy, print memory.

- Type: distinctive display face only when justified; quiet body system
- Colour: paper/ink roles or another restrained editorial palette
- Layout: asymmetric or chapter-like structures when they support reading
- Motion: usually low-medium; no automatic bounce
- Candidate macros: Long Document, Letter, Quote-Led, Manifesto, Type Specimen, Split Studio
- Candidate nav/footer: N6, N9; Ft1, Ft4, Ft5, Ft6

## modern-minimal

**Bias:** precision, calm chrome, product credibility.

- Type: clear product typography; mono only where data/code semantics justify it
- Colour: near-monochrome can work; accent roles stay deliberate
- Layout: strong grid and density appropriate to tool/marketing context
- Motion: restrained feedback usually matters more than decorative scroll theatre
- Candidate macros: Workbench, Feature Stack, Bento, Component Playground, Narrative Workflow, Stat-Led with real metrics
- Candidate nav/footer: N1b, N2, N5, N13; Ft2, Ft4

## atmospheric

**Bias:** immersion, light/material, depth.

- Type: one coherent display/body system; mono captions only when justified
- Colour: dark bases are common but not required; light/bloom effects need a role
- Layout: fewer stronger full-bleed moments can replace repeated card sections
- Motion: medium-high only when purpose/frequency and reduced-motion gates pass
- Candidate macros: Marquee Hero, Photographic, Feature Stack, Map/Diagram
- Candidate nav/footer: N5, N10; Ft5, Ft8

## playful

**Bias:** warmth and approachable craft without uncontrolled ornament.

- Type: friendly forms when they fit brand and readability
- Colour: brighter accents can work within a coherent role system
- Layout: cards/illustration only when they support content and identity
- Motion: springy micro-feedback can work when frequency and brand support it
- Candidate macros: Bento, Conversational FAQ, Portfolio, Letter
- Candidate nav/footer: N7, N2; Ft7, Ft6

## Cross-genre review leads

Patterns such as purple-blue gradients, generic font choices, three equal feature
cards, nested decorative cards, side stripes, italic display reflexes, generic
footer structures, or hand-drawn browser chrome are anti-slop review leads. They
fail only under the applicability rule in `anti-slop-gates.md`, not because the
token or pattern exists by itself.

Invented metrics, fake evidence, inaccessible contrast, broken interaction, and
other truth/safety failures remain blockers regardless of genre.
