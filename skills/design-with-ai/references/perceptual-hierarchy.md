# Perceptual hierarchy

Load this only when a concrete surface has an unresolved hierarchy, grouping, figure/ground, or visual-salience question. It is a bounded diagnostic inside `design-with-ai`, not a second router and not a substitute for user research, accessibility testing, task completion evidence, or project design authority.

## Perceptual checks

### Proximity and common region

Items that sit close together or share a container are read as a group. Use that grouping only when the items actually share a semantic role, task, state, or decision. If unrelated controls look grouped, separate them through spacing, region, or hierarchy before adding decoration.

### Similarity and semantic consistency

Repeated shape, colour, typography, size, icon treatment, or motion implies related meaning or behaviour. Similarity should reinforce semantics, not merely make the composition tidy. Do not style different roles identically when that treatment promises the same action, status, or priority.

### Connectedness and continuity

Lines, steppers, alignment paths, repeated edges, and directional motion imply sequence or relationship. Use connectedness and continuity only when the underlying flow is real. A decorative connector must not invent dependency, chronology, or navigation that the product does not have.

### Figure/ground

Primary content and actions must remain distinguishable from background, shell, overlays, decorative layers, and secondary chrome. When foreground and background collapse into the same contrast/material treatment, users lose the intended reading order even if every element is individually legible.

### Visual weight versus semantic priority

Compare semantic priority with the strongest visual signals: area, contrast, saturation, isolation, type scale, elevation, imagery, and motion. The most visually forceful element should not be a decorative badge, secondary metric, or incidental chrome while the primary job is quiet. Record accidental salience as a defect.

### Competing accents

Several simultaneous high-salience elements flatten hierarchy. Prefer a deliberate focal order over many equal accents. Reduce emphasis, regroup, or change placement before adding another highlight.

## Blur / thumbnail diagnostic

When rendered evidence is available, optionally inspect a downscaled or defocused view so text detail recedes. The intended first, second, and third focal zones should still be broadly recognizable from mass, contrast, spacing, and placement. If decoration, chrome, or a secondary block dominates after blur/downscale, revisit the hierarchy.

This blur or thumbnail check is a **diagnostic, not a usability proof**. It cannot establish comprehension, accessibility, conversion, or task success, and it never replaces focus-order checks, contrast checks, content review, interaction testing, or representative user evidence.

## Authority

Project tokens, accepted design rules, explicit user direction, and the selected visual world still govern the solution. Gestalt principles describe likely perception patterns; they do not authorize a generic layout recipe or override product semantics.
