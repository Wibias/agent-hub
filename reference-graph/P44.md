# P44: executable local shadow kill-switch rehearsal (production NO-GO)

The original P40 rollback **plan** did not mutate state. P44 exercises an actual local state latch: after parity mismatch, exception, timeout, or manual revoke, further Standard/Deep shadow probes are suppressed until a new test harness is created.

- Default-off; only `armForRehearsal` with `mode:'isolated-shadow-rehearsal'`, `default_off:true`, `production_route_wiring:false` and Standard/Deep profiles can allow an injected **test-only** shadow probe.
- Every request uses the authentic P11 Legacy result. The P11 router controls exactly-once usage recording; Graph candidates/patterns never replace the public result.
- Quick is never probed; no live service key, file write, DB mutation, cron task, deployment, router import or source-pin change.
- Failure disables subsequent probes within this local process, a real in-memory kill switch rather than a nonexecuting report. The timeout passes an AbortSignal to the injected probe; that probe still needs to honor the signal.
- Does **not** operate on live production workers, global configuration or already-active Graph routing. It cannot prove a production rollback. A separate independently reviewed deployment controller and actual prod-like rollback rehearsal remain OPEN in [#275](https://github.com/Wibias/agent-hub/issues/275).

P44, like P40/P41/P42/P43, is strictly a default-off unmerged Draft component. All activation flags remain false.
