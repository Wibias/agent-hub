# P45: host-local process-shared OFF latch (not production routing)

**Review-only, default-off.** A monotonic same-host filesystem marker coordinates local Standard/Deep shadow rehearsals across OS processes. It does not import into P11/query, publish credentials, or grant Graph activation.

- A marker is created exclusively and flushed; a partial marker is interpreted as OFF. Missing/unreadable or untrusted directories also fail closed. The module has no re-enable API.
- An absent marker does not grant any privilege. The operator must additionally use the explicit isolated-shadow-rehearsal, default_off=true, production_route_wiring=false and Standard/Deep-only scope, plus P44 laboratory arming.
- The P45 wrapper polls while a P41-style shadow probe runs. Another local process can create the OFF marker; the wrapper aborts the injected signal. Probe error or parity mismatch persists an OFF marker visible to other workers.
- Tests use real child Node processes for cross-process revocation, post-restart block, in-flight cancellation and P44 Legacy fallback.

**Not production-grade:** A host-local marker does not coordinate different machines, containers without a shared mount, or remote workers. A filesystem poll cannot guarantee a perfectly atomic barrier between checking the marker and starting an HTTP request. A filesystem administrator can delete markers; the monitor is not durable after process death. Production requires an independently reviewed authenticated distributed revocation/lease system and an actual rollback drill.

P11, Quick/P17, query.mjs, P33 and historical P35 pins are unchanged. P45 does not enable a route and does not approve Draft #276. Release obligations remain in issue #275. Activation: NO-GO.
