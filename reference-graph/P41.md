# P41: server-only Standard/Deep shadow probe (NO-GO for routing)

**Draft-only.** This is an operator-side one-request bridge from P40 offline parity to live P31 candidates, not an enabled product route.

- Calls existing P11 with explicit `graphMode:'legacy'` and `recordUsageEnabled:false` to validate the local Legacy request and preserve legacy authority.
- Requires a separately archived P40 read-only witness, its exact preapproved SHA256, matching dedicated project, UTC-current and <15-minute freshness; rejects unauthenticated or mismatching inputs **before** network.
- Requires server-only `sb_secret_` credential (supplied by a trusted operator process, never stored in code). Calls the existing bounded P30 transport with `accessMode:'server'` and exact expected count, legacy ID-set digest and refreshed_at.
- Checks the P29 profile selector's ordered Standard/Deep legacy IDs and selected pattern IDs against current local Legacy P11 selection, without writing usage and without returning records or candidate text.
- Returns only an allowlisted aggregate with `authoritative_source:'legacy-control'`, `public_output_unchanged:true`, `activation_authorized:false` and `graph_runtime_activated:false` even for exact parity. A fetch failure, stale witness, mismatched refresh or mismatch is nonauthorizing and retains legacy authority.
- **Not imported** into `reference-graph/p11-runtime-router.mjs`, `query.mjs`, Quick/P17, P35 or any production request path. The historical pins remain immutable.
- Offline CI mock uses a synthetic server-only P30 GET and verifies 48 Standard/Deep cases; this is **not** current independent live P33/P34/P37 evidence, nor a production rollback rehearsal.
- The P40 full-parity audit remains the trusted aggregate lane to test complete public JSON output; P41 only measures per-request record and pattern parity.

**Before any production integration:** separately reviewed authenticated release controller, nonce/revocation, default-off per-profile eligibility, server-only credential boundary, exactly-once usage recording, P11 public-output equivalence, monitored p95/error/quality budgets, canary/kill-switch and actual rollback rehearsal. All remain tracked in [#275](https://github.com/Wibias/agent-hub/issues/275). No activation is authorized by P41.
