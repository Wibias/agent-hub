# P65: default-OFF Standard/Deep server-side shadow adapter

**Status: draft-only, isolated rehearsal. Production activation remains NO-GO.**

P65 is a deliberately small bridge between the already-tested P41 protected read-only server GET and P44's fail-closed rollback harness. It makes neither P11 nor the public CLI import the adapter, and never replaces the authoritative Legacy output. It performs no Supabase writes, database changes, scheduled work, secret logging, or usage recording. Quick does not enter this adapter.

## Exact boundary

- A new adapter starts **OFF**, even if a prior instance ran and succeeded. It does not import an environment variable to enable itself.
- Only `armForRehearsal()` with an exact, explicit `isolated-server-shadow-rehearsal` scope, pinned source commit, dedicated Supabase project, `default_off=true`, `production_route_wiring=false`, and Standard/Deep profile selection permits a P41 read-only server shadow request. No live owner release or signature is inferred from this caller-controlled scope.
- P41 verifies fresh P40 witness bytes and SHA-256, project identity, immutable refresh instant and parity, and uses a bounded server-only P30 GET with AbortSignal. The service key is supplied only in the trusted server process, never passed to a browser or CLI argument.
- P44 computes the authentic P11 Legacy output first. Even on an exact P41 response, **the public output is unchanged Legacy**. Failed parity, error, timeout or manual revoke abort in-flight shadow probes, latch further probes OFF for the instance, and preserve Legacy output. No retry and no re-arm after the latch.
- `run()` rejects Quick; the existing P11/query code, Quick Graph switch, usage logs, P35 historical pins and runtime defaults are untouched. The adapter turns off usage recording for isolated rehearsals.
- An instance restart returns to OFF. This is a **per-process rehearsal kill-switch**, not a production cross-host revocation, a genuine Graph cutover or a production rollback. An unauthorized caller who can execute server code could construct a new adapter, so this is not a production release authority.

## Isolated example (no real secrets)

```js
import { createP65ServerShadowAdapter } from './p65-server-shadow-adapter.mjs';
const adapter = createP65ServerShadowAdapter({
  checkoutSha: '<40-char checkout commit SHA>',
  sourceWitnessJson: '<P40 witness file text>',
  sourceWitnessSha256: '<64-char witness SHA256>',
  serviceKey: '<trusted-server secret, never browser code>',
});
// Without the following explicit lab-only arm, run() always serves Legacy,
// does not request P30 and does not read the provided key.
adapter.armForRehearsal({
  mode: 'isolated-server-shadow-rehearsal',
  project_ref: 'vrznfnxzlxaavpqbzbzd',
  source_commit_sha: '<same 40-char checkout commit SHA>',
  profiles: ['standard', 'deep'],
  default_off: true,
  production_route_wiring: false,
});
// adapter.run({ records, patterns, request, now }) returns {result, routing, shadow}.
// adapter.revokeForRehearsal() permanently stops further probes on this instance.
```
