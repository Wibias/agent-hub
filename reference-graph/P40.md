## Why this increment exists

The previous P31 refresh-function receipt from 2026-11-08 is lost. A later P7/P31 match cannot certify that earlier P33/P37 HTTP snapshot. Never invent or retroactively "recover" the old receipt. The P35 owner waiver permitted only #274's code merge. P35 successor governance is tracked in issue #275.

This change adds a separate **read-only, same-statement** P7-source versus P31-projection witness. The new schema is deliberately named \`reference-graph.p40-readonly-source-witness.v1\` and has a different evidence method from the P31 refresh-function receipt. It checks *all candidate DTO fields* (plus primary_stratum from current_assets), not merely membership. It carries counts, hashes, exact UTC refresh/observation times and mismatch counters, never raw candidates. It creates no functions, views, grants, migrations or cron jobs.

The P33 evaluator accepts this **versioned alternative** only when its raw bytes match a SHA-256 independently pinned by the operator, the witness is from the bound project and current UTC date, and it is at most 15 minutes old. It still checks that the *live P30 HTTP response* has the **exact same refreshed_at** timestamp and ID-set as the independently archived witness. A witness digest computed by the very same untrusted workflow is not independent provenance.
